Taaru, l'atelier dans le téléphone

Quatre parcours à faire tester par le tailleur, sur votre téléphone, sans rien expliquer d'abord.

  1. Accueil : « Quelles tenues devez-vous livrer aujourd'hui ? »
  2. Nouvelle commande : « Enregistrez la commande d'une cliente qui veut deux tenues pour la Tabaski. »
  3. Détail : « La tenue est prête : prévenez la cliente et encaissez le solde. »
  4. Mesures : « Prenez les mesures de cette cliente avec votre mètre ruban, directement dans le téléphone. »

Notez où le tailleur hésite, ce qu'il cherche sans le trouver, et les mots qu'il emploie.
